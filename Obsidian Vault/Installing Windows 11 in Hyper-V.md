1. www.microsoft.com/software-download/windows11 << ISO file here
2. create new VM in Hyper-V, name it, and select where it will be stored
3. select Generation 2 under Specify Generation in the wizard
4. enter minimum 4096 MB of memory and select Dynamic Memory
5. connect to virtual switch for internet access
6. create virtual hard drive with at least 64 GB capacity
7. point to ISO file and hit Next
8. go to VM settings, select Security and check Enable Trusted Platform Mode, hit Apply
