<u>Objectives</u>
1. configure proxy settings via Internet Options
2. manage user accounts
3. manually add printers
4. uninstall applications and install Windows applications

------
- **Internet Options**
	- accessed via control panel
	- settings on General, Security, Privacy, Programs, and Advanced tabs only affect Internet Explorer, not Edge or any third-party browsers
	- options in Content tab are related to certificates
	- Proxy configuration:
		- Connections tab > LAN settings > check Automatically detect settings > uncheck Use an automatic config script > check Use a proxy server for your LAN
