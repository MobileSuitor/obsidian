- **Critical Windows Settings** 
	- *Windows updates* - always install any pending updates and verify Windows Update is configured to automatically allow updating
	- *Antivirus/Anti-malware software* - verify that anti-malware software is configured to scan regularly and that it is up to date
	- *Network security setting* - use Network and Sharing Center to check that the network security type is set correctly for the optimum firewall settings
	- *Backups of user data, the Windows volume, and system files* - verify that backup routines are running as expected
	- *Uninstall software you no longer need* - this helps overall performance by reducing the number of startup processes running in the background and freeing up hard drive space
	- *Clean up the hard drive* - a drive needs at least 15% free space so Windows can operate smoothly
	- *For laptops, verify power options* - set power options to conserver power and increase the time before a battery pack needs recharging
- **Useful Settings and Control Panel Applets**
	- *Accounts* - contains Windows account info and allows you to link your account to a Microsoft account. Also includes email and app accounts, sign-in options, Microsoft account sync settings, options to sign in to work or school networks, and options to add new user accounts to the computer
	- *Apps* - uninstall applications, set default applications, and check other application settings
	- *Devices (Bluetooth & devices in Windows 11)* - find settings here for printers and scanners, connected devices, Bluetooth, mouse and touch pad devices, typing, AutoPlay, and USB
	- *Gaming* - trash game settings that hinder performance 9/10 times
	- *Network & Internet* - network status, data usage info, and settings for different connections (Wi-Fi, Ethernet, VPN, hotspots)
	- *Personalization* - settings for backgrounds, colors, lock screen, themes, taskbar, etc.
	- *Privacy* - settings to restrict or allow Windows or apps access to information and resources, including location, camera, microphone, notifications, speech, typing, account info, contacts, calendar, call history, email, file system, etc. Can also choose which apps run in the background
	- *System* - catchall information and settings that affect functions of the computer, such as those for adjusting display, notifications, power, sleep, and storage
	- *Time & Language* - settings for date and time, region and language, and speech
	- *Update & Security* - tools and settings found here include Windows updates, backups, and recovery
- **Power Options** 
	- *Sleep mode (standby/suspend)* - Windows saves current state of open files to memory and saves some of the work to the hard drive, then everything is shut down except memory and enough of the system to respond to a wake-up. Can still perform Windows updates and scheduled tasks in sleep mode
	- *Hibernation* - saves all work to the hard drive and powers down the system. When powering back on Windows reloads its state, including all open applications and documents
- **Plans for Disaster Recovery**
	- Six options for backups
		- **Option A: use no backup** 
		- **Option B: Create and maintain your own backups** - Windows File History and Windows Backup and Restore can be used for this scenario. Allows complete control over data and backups, but also means you are solely responsible for all backup and recovery operations
		- **Option C: Backup to the Cloud** - using any cloud service that copies data when connected to the Internet
		- **Option D: Keep data in the public Cloud** - using Microsoft OneDrive or Google Drive
		- **Option E: Data is kept on a local file server and backed up to private media** - gives more control of data to the network admin, but complicates access to data when off the local network
		- **Option F: Data is kept on a local file server and backed up to the Cloud** - main advantage is the cloud service is responsible for all backup routines and supporting recovery operations
	- *3-2-1 backup rule* - keep **three** copies of data (the original/production data, and two backups), **two** media types (ex. an external hard drive and the cloud), and **one** copy off site
	- *Backup types* 
		- <u>Full backup</u> - backs up all data designated for backup
		- <u>Incremental backup</u> - backs up only files that have changed or been created since the last backup whether that backup is itself an incremental or a full backup
		- <u>Differential backup</u> - backs up files that have changed or been created since the last full backup. A differential backup does not consider if other differential backups have been performed footnote 
	- *Backup routines* - should always begin with a full backup and then use either incremental or differential backups several times, with additional full backups made occasionally. When something is recovered, the recovery process must reconstruct the lost or corrupted items from the latest full backup and then apply any changes reflected in all the incremental backups since the last full backup
		- once a routine is established, you should test the recovery plan. Erase a file and use recovery procedures to verify that it can be recreated from the backup, verifies the backup media works and the recovery software is effective
- **Creating Backups**
	- *Back up User Data and the System Image*
		- <u>System image</u> - the backup of the entire Windows volume; it can also include backups of other volumes. Works **_only_** on the computer that created it
		- **_Note_**: Windows only uses one backup tool at a time, either <u>File History</u> or <u>Backup and Restore</u>. One must be turned off to use the other, and both tools only allow for one backup routine
		- **Windows File History** - simple backup utility that is easy for users but gives limited control over backups. First makes a full backup to another medium, then scans for file and folder changes at a designated time interval and keeps as many generations of backups as free space allows 
			- [[Perform Backup Options to Allow for Lost File Recovery]]
		- **Windows Backup and Restore** - offers more granular control of backups than File History
			- [[Setting up Windows Backup and Restore]]
		- **Windows Backup App** - syncs files and creates backups of system preferences to be stored on OneDrive. Does not create a full system image and it cannot restore individual files
- **System Protection**
	- Automatically backs up system files and stores them at regular intervals. These snapshots are called <u>Restore Points</u>, and include Windows system files that have changed since the last restore point was made
	- *System Restore* (rstrui.exe) - restores the system to its condition at the time a restore point was made. Does not alter user data on the hard drive
- **Drive Optimization and Management** 
	- *Defragment and Optimize Drives* (dfrgui.exe) - utility that automatically defragments hard drives and trims SSDs weekly
	- Defragment - rearranging fragments or parts of files on the hard drive so each file is stored on the drive in contiguous clusters
		- Solid-state drives have defragmenting disabled by default, but performance of SSDs can benefit from trimming (erasing a block on the drive that is filled with unused data)
	- *Disk Management* (diskmgmt.msc) - tool for managing hard drives, can be used for the following:
		- managing partitions
		- preparing a new drive for first use
		- mount a drive
		- use Windows dynamic disks
		- troubleshoot problems with the hard drive
	- Windows Dynamic disks - a way to partition one or more hard drives so that they can work together to increase space for data storage or to provide fault tolerance or improved performance. Several dynamic volumes can work together to collectively present a single dynamic volume to the system. Some advantages:
		- improve reliability 
		- extend a volume across multiple drives (spanned volume)
		- improve performance and/or provide fault tolerance
	- RAID (redundant array of independent disks)
		- RAID 0 - joining hard drives together to improve performance (striping). Work is shared between two hard drives, but does not provide fault tolerance
		- RAID 1 - copying one hard drive to another as a backup (mirroring). Provides fault tolerance, but can reduce performance because the drives operate at the speed of the slowest drive and all data must be written twice
- **Troubleshooting with Disk Management**
	Some examples of disk and volume statuses and what they indicate
	- *Unknown* - the boot sector most likely is corrupted, which may have been caused by malware
	- *Unreadable* - file system database cannot be read. Try rebooting
	- *Failed* - drive is damaged, or file system is corrupt. Replace data cable to drive and ensure it is receiving power. Data on a failed volume is likely to be lost
	- *Active* - one volume on an MBR system will be marked as such. This is the volume that startup BIOS/UEFI looks to for an OS boot manager to load
	- *EFI System Partition* - in GPT systems one volume will be marked as such. BIOS/UEFI looks to this volume to find an OS boot manager to load an OS
	- *Unallocated* - space on the disk that has not yet been partitioned
	- *Formatting* - appears when formatting is taking place on a volume
	- *Basic* - assigned by Windows when a hard drive is first sensed. Can be partitioned and formatted as a stand-alone hard drive
	- *Dynamic* - the following status indicators apply only to dynamic disks:
		- **Online** - indicates the disk has been sensed by Windows and can be accessed by either reading or writing to the disk
		- **Online (errors)** - region of the disk is giving errors. Try returning the disk to online status. If the volume status does not return to healthy, back up all data and replace the drive
		- **Offline** or **Missing** - dynamic disk is corrupted or unavailable. May be caused by corrupted file system, bad cable, failed hard drive, or another hardware problem
		- **Foreign drive** - occurs when moving a hard drive that has been configured as a dynamic disk on one computer to another. Import foreign disks to fix
