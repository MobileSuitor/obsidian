1. Open Control Panel in classic view, click Backup and Restore (Windows 7). Click Set up backup
2. Select device or location to hold the backup (Pro and Enterprise allow you to backup to a network location)
3. Select Let me choose in order to select folders for backup
4. If the backup medium can hold the system image, the option to include it is selected by default
5. Verify correct items are selected, and hit Change schedule to adjust the default settings.
6. Click Save settings and run backup
