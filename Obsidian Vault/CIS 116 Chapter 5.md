*Objectives*
	- Understand the steps to load Microsoft Windows into a VM
	- Understand the steps needed to install the VMware tools or VirtualBox guest additions into a Windows virtual machine
	- Examine some VM configuration options
	- Examine some optimizations for a Windows VM

- **Virtual Machine Tools**
	- VMware tools/VirtualBox guest additions are installed to enhance the user experience, improve performance, and help manage the VM
- **Virtual Machine Optimizations**
	- Some processes that run on Windows are not necessary in a virtual environment, disabling them can save processing power and memory 
	- can also remove things like wallpapers and screen savers
