<u>Objectives</u>
- manage device drivers
- configure region settings
- evaluate hardware compatibility and prereqs for an OS update 
- determine application requirements
- perform system reset

<u>Scanning for hardware changes</u>
- open Device Manager, right click any category and select **Scan for Hardware Changes**
- once a scan is completed, any newly discovered hardware will have its drivers automatically installed
- disabling and reenabling a device can be a troubleshooting step
- most devices will be automatically installed when they connected, but rescanning can help find them if they don't show up
--------------------------
<u>Configuring Region Settings</u>
- generally, time and date settings should be left to sync automatically for accuracy
- default time source of Windows is <u>time.windows.com</u>, but this can be changed through data and time settings or the control panel
- pre-set time and date regional formats are available, but these settings can be customized through *Clock and Region* control panel section > *Change date, time, or numbers formats*
- Regional format settings can be changed in *Time & Language* > *Language & Region*
----------------------
