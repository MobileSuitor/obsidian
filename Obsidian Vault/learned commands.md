 - ==🟣ls== - lists stuff in a directory
	- -R option is like tree but uglier
	- -a option shows hidden files
	- -l option lists long format (permissions and other info)
	- -h option lists file sizes in human readable format
	- -S option sorts files by sizes 
- ==🟣mv== -  moves files and directories or renames them. Can do both simultaneously
	- rename syntax - ==🟣mv \[old name] \[new name]==
	- move syntax - ==🟣mv \[source path] \[destination path]==
	- move + rename syntax - ==🟣mv \[old path] \[new path with new name]==
- ==🟣cp== - copy files and directories
	- basic syntax - ==🟣cp \[source] \[destination with new name]==
- ==🟣2>== - redirects error messages to a file
	- useful for logging error messages, troubleshooting and record keeping
- ==🟣tree== - tool that helps visualize the structure of directories and subdirectories in a tree-like format
	- requires installation with ==🟣sudo apt -f install tree -y==
	- ==🟣tree -L 1 /== displays the structure of the root directory with a depth of one level
- ==🟣less== - view contents of a file or output in a scrollable manner without opening in an editor
	- use / followed by keyword to search output
- ==🟣$(command)== - captures output of a command and uses it as part of another command
	- ==🟣output=$(ls)
	  echo "The files in the current directory are: " $output== - ls command is executed, output of ls is captured and stored in output variable, output variable is used to display list of files
- ==🟣find== - used to search for files and directories within the filesystem, searches based on attributes such as name, size, type, and more.
	- basic syntax - find \[starting_directory] \[options] \[expression]
	- \[expression] defines what kind of files or directories to look for (file names, file types)
	- \[options] specifies what you're searching for (-name, -type f, -type d)
- ==🟣which== - used to locate the executable files for commands within the directories listed in your PATH
	- -a option shows all instances of an exe in PATH. Helpful for debugging or finding where a command is located
- ==🟣PATH== - not a command, but an environmental variable that tells the shell where to look for exe files when you run a command. Contains a list of directories separated by colons. If a directory is not in PATH, the shell will not find commands in that directory
	- searches left to right, and the first match is the one where the shell will run the command from
	- use to add your own directories so scripts will run like commands
	- ==🟣export PATH=$PATH:/new/directory== < adds new directory to the end 
- ==🟣grep== - used to search for specific text within files or within the output from other commands when used with pipes
	- -i option ignores case
	- -v option excludes lines that contain the argument
	- -r option searches all files recursively within a directory 
	- -c option counts how many lines contain the argument
	- does not always need a file, can operate directly on input streams
	- use ^ to search for character at start of line
- ==🟣SHLVL== - not a command, but an environmental variable that tracks how many nested shells you are in
	- /bin/bash starts a new nested shell session
	- exit leaves the current nested shell session
	- note: scripts start a new shell session when executing
- Session variables - variables that exist only in the current shell session. Useful for temporary values, quick testing, and script-specific data
- Environment variables - variables that are passed from a parent shell to child shells and processes
- ==🟣export== - makes a variable so it is inherited by child shells and scripts
- ==🟣env== - lists environmental variables
- ==🟣set== - lists shell variables, environmental variables, shell functions, and shell settings
- ==🟣alias== - lists all aliases, creates one if specified as argument
	- when created directly in the terminal, they only last for the current shell session
	- save in a startup file so they persist between sessions, such as ~/.bash_aliases
	- ex. copy with verbose and recursive --> ==🟣alias \[name]='cp -vr'==
- ==🟣unalias== - removes an alias
- ==🟣chmod== - change permissions
	- syntax - ==🟣chmod \[who]\[+/-]\[permissions] \[file/directory]==
		- \[who] - u (user owner), g (group owner), o (other), a (all)
		- \[+/-] - add or remove permission
			- can also use \[=] to overwrite permissions with selection
		- \[permissions] - r, w, x
		- ==🟣chmod u-r filename== - remove read permissions for user owner
		- verify changes with ==🟣ls -l==
- ==🟣adduser== - creates a new user
	- new accounts are treated as other on existing files and directories
	- handles various setup tasks, updates several system locations
		- /etc/passwd
		- /etc/shadow
		- /etc/group
		- /home
- ==🟣usermod== - adding accounts to a group 
	- ==🟣sudo usermod -aG groupname username==
		- -aG = appends to group
- ==🟣gpasswd== - removing accounts from group
	- ==🟣sudo gpasswd -d username groupname==
- ==🟣chage==
	- forces user to set new password
		==🟣sudo chage -d 0 username== - prompts user on next login (0 days) to create new password
- ==🟣umask== - determines default permissions. Specifies which permission bits should be removed when new files and directories are created. Only affects newly created items, is not retroactive
	- use to display current permission mask
	- directories by default have full permissions (777), files have all but execution permissions (666)
	- umask value is subtracted from these defaults to determine final permissions
		- ex 022 default mask
			- file base (666) rw-rw-rw- ---> final file permission (644) rw-r--r--
- ==🟣chown== - changes ownership. Can change user owner, group owner, or both.
	- examples
		- change user owner: ==🟣sudo chown user1 file==
		- change group owner only: ==🟣sudo chown :group1 file==
		- change both: ==🟣sudo chown user1:group1 file==
- ==🟣chgrp== - change group ownership only
	- syntax: ==🟣sudo chgrp groupname filename==
- ==🟣userdel== - delete user account from the system
	- does not automatically remove their home directory unless -r option is used
- ==🟣groupdel== - deletes a group from the system
- ==🟣file== - identifies what type of file you are examining
		- ==🟣file /dev/sda== --> outputs ==🟣block special==, indicating /dev/sda is a block device
- ==🟣df== - disk free command, shows how much disk space is used and available on mounted filesystems, and what mount point they are at
	- syntax: ==🟣df -h | grep ^Filesystem && df -h | grep ^/dev==
- ==🟣gdisk== - creates GPT partition
	- syntax: ==🟣sudo gdisk /dev/\<disk you want to partition>==
	- ==🟣n== - creates new partition
	- ==🟣w== - writes changes to disk
- ==🟣mkfs== - creates filesystem within a partition
	- syntax: ==🟣sudo mkfs -t ext4 /dev/sdb1==
- ==🟣mount== - mounts a new partition, filesystems, or devices to directory in Linux
	- syntax: ==🟣sudo mount \[options] \<device> \<directory>
	- does not persist after reboot
	- must add to file /etc/fstab in order to persist
- ==🟣umount== - unmounts a new partition, filesystem, or device from a mount point
	- syntax: ==🟣umount \[option] \<mount_point>==
- **Editing /etc/fstab**
	- fstab entry: ==🟣/dev/sdb1 /home ext4 defaults 0 0==
		- /dev/sdb1 - partition to mount
		- /home - where the filesystem will be accessible
		- ext4 - filesystem type
		- defaults - uses standard mounting options
		- first 0 - disables backups by the legacy dump utility
		- second 0 - disables automatic filesystem checking by fsck at boot for this entry
	- test changes made to /etc/fstab
		- start with device unmounted
		- issue ==🟣sudo mount -a==
			- attempts to mount filesystems listed in fstab that aren't already mounted
		- issue ==🟣sudo systemctl daemon-reload==
			- reloads system configuration, including mount units generated from /etc/fstab
		- use ==🟣df== to check that mount took place
- ==🟣ps== - process viewing utility
	- ==🟣-e== - displays entire list of processes across all terminals, including daemons
	- add ==🟣 | head== to display only the first 10 lines of output
	- ==🟣-l== - displays additional process details, including PPID, PRI, and NI
		- NI is nice value, lower nice values get higher priority and vice versa
	- ==🟣ps aux== - displays detailed information about processes across the system
		- a - shows processes associated with terminals belonging to other users
		- u - displays user-oriented details, including CPU and memory usage
		- x - includes processes without a controlling terminal
- ==🟣top== - interactive screen listing processes in near real time. Scroll using PgUp and PgDown
- ==🟣htop== - like top, but with color coding and graphs. Not standard in all distros
- ==🟣nice== - sets the nice value when starting a new process
	- syntax: ==🟣nice -n value command==
- ==🟣renice== - changes the nice value of an already running process
	- syntax: ==🟣renice value PID==
- ==🟣jobs== - lists jobs managed by your current shell
	- includes jobs running in the background and jobs that have been suspended
- ==🟣kill== - sends a signal requesting that a process terminate, gives the process a chance to clean up before exiting
	- syntax: ==🟣kill \<PID>==
	- ==🟣-9== - terminates immediately without cleanup
- ==🟣killall== - sends termination signal to processes with specified name, do not need to know PID
- ==🟣fg== - brings job into the foreground (can't enter commands while running)
	- syntax: ==🟣fg %job_number==
- ==🟣bg== - resumes a suspended job in the background
	- first, suspend a foreground process with **Ctrl+Z**
	- syntax: ==🟣bg %job_number==
