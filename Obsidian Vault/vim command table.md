
| Command | Description                |
| ------- | -------------------------- |
| **i**   | insert mode (file editing) |
| **x**   | cut character              |
| **dw**  | cut word                   |
| **dd**  | cut full line              |
| **yw**  | copy word                  |
| **yy**  | copy full line             |
| **p**   | paste                      |
| **:**   | enter command mode         |
| **:1**  | go to line number 1        |
| **:w**  | write the file, save       |
| **:q**  | quit                       |
| **:ql** | quit without saving        |
| **:wq** | write and quit             |
